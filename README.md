# AI Voice-Based Presentation & Document Assistant

A production-grade, lightweight Proof of Concept (POC) built with Python and FastAPI. This assistant engages in real-time voice conversations to gather requirements and automatically generates structured PowerPoint presentations and PDF summaries.

## Core Tech Stack
- **Backend:** Python + FastAPI
- **Voice Pipeline:** LiveKit Python SDK
- **Data Layer:** SQLModel (SQLite)
- **Document Generation:** python-pptx & ReportLab
